# python-passguard
PassGuard
I just finished building my first real desktop app in Python, and I’m pretty proud of it. 🔐

For Lab 1 of my Python course at GHANA COMMUNICATION TECHNOLOGY UNIVESITY, I built PassGuard, a password security toolkit with a Tkinter interface. It checks your password strength live as you type, with a bar that goes from red to green. It flags common passwords like “123456” and “password” as very weak, and it generates strong random passwords you can copy in one click. It also hashes passwords with SHA-256 and keeps a history that saves only the hash, never the real password.

Here’s what I took away from it:

Building a desktop GUI with Tkinter
Event-driven programming, where the app waits and reacts to key presses and clicks
Why secrets is the right choice for passwords and random is not
How hashing protects users when a database gets leaked

It was also fun to see my code turn into something I could actually use and click around in.

Thank you to my lecturer for such a hands-on lab!
